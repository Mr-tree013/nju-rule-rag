# 南京大学奖助学金与资助政策

## 官网：https://www.nju.edu.cn/zsjy/jzxj.htm

## 总体概况
- "奖、助、贷、补、勤、减、免、偿"一揽子学生资助政策
- 2024年度发放学生资助资金达1.15亿元，获助28940人次
- 四维发展型资助体系：经济支持、信息支持、情感支持、精神支持

---

## 本科生资助

### 奖学金
| 奖项 | 说明 |
|------|------|
| 国家奖学金 | 中央财政出资，奖励特别优秀本科生 |
| 国家励志奖学金 | 品学兼优的家庭经济困难学生（南字发〔2021〕142号） |
| 校级奖学金 | 详见《学生手册》 |
| 社会捐赠奖学金 | 每年运行超180项，总额超1700万元，获奖超3100人次 |

### 助学金
| 类别 | 说明 |
|------|------|
| 国家助学金 | 南字发〔2021〕141号，面向家庭经济困难学生 |
| 社会捐赠助学金 | 瑞华启梦、瑞华春雨、新鸿基地产郭氏基金、真维斯等数十项 |
| 临时困难补助 | 全年开通，针对突发灾害、家庭重大变故 |

### 其他资助
- 勤工助学：《南京大学学生勤工助学管理办法》
- 学费减免：《南京大学本科生学费减免实施办法》
- 绿色通道：新生入学时开设，发放爱心礼包、路费补助和生活补助

## 特色资助项目

### "雨花斑斓"成长计划
- 2010年启动，面向家庭经济困难学生
- 涵盖社会适应、社交、文艺、媒介、就业创业五大模块数十门课程
- 每年约500名学生参与，2024年12月登上央视

### "圆梦翱翔"国际交流计划
- 面向家庭经济困难学生设立国际交流奖学金
- 每年约20名学生获10,000-50,000元赴境外交流
- 20-30名学生集体赴境外研修提能

### 精准暖心举措
- **"悄悄"伙食补助**：消费数据分析，悄悄为消费过低学生校园卡充值1000元
- **生日祝福**：困难学生赠送20元电子生日礼券
- **"七彩暖心包"**：连续32年为困难学生发放御寒冬衣
- **"一分钱暖心早餐"**：考试周面向备考学生
