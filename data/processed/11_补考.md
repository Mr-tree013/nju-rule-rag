## 二、补考规定要点

### 2.1 补考资格

| 情形 | 补考资格 |
|------|---------|
| 首次修读课程不及格 | ✅ 可申请 1 次补考 |
| 期末成绩或总评为 0 | ⚠️ 需上传申请材料，经审核通过 |
| 因旷考/违纪成绩为 0 | ⚠️ 表现良好可申请，需审核 |
| 重修不及格 | ❌ 不得补考，只能再次重修 |
| 体育课无故缺课达四次 | ❌ 不予补考，须重修 |

### 2.2 补考成绩计算

- 按平时成绩（含期中）+ 补考卷面成绩**综合评定**
- **成绩记载**：原成绩注明"无效"，补考成绩注明"补考"
- **学分绩**：补考通过一律按 **60 分** 计入学分绩

### 2.3 重修规定

| 情形 | 处理 |
|------|------|
| 首次不及格 | 先补考 |
| 补考不及格 | 申请重修（缴纳学分学费） |
| 重修不及格 | ❌ 不得申请补考，只能再次重修 |
| 已通过但 < 80 分 | 可申请重修 1 次 |
| 已通过且 ≥ 80 分 | ❌ 不得申请重修 |

重修成绩注明"重修"字样，原成绩注明"无效"，以重修成绩计入学分绩。

## 三、学籍管理相关

来源：南京大学普通全日制本科生学籍管理细则

| 项目 | 规定 |
|------|------|
| 学制 | 四年制最长修业年限 ≤ 6 年；五年制 ≤ 7 年 |
| 退选 | 开课 2 周内退选不记载；3–8 周注明"退选"无成绩；8 周后不得退选 |
| 免修不免考 | 每学期最多 2 门（思政、军事、体育、实践类课程除外） |
| 休学/复学 | 集中审核时间为每学期开学两周内 |

## 五、F=2.2 原因分析 & 建议

现有 7 份数据但 F 仍为 2.2，可能原因：

1. **RAG prompt 问题**：用户问法多样（"挂科了怎么办""没过能补吗""补考怎么报名"），现有 prompt 模板可能没有覆盖所有口语化问法
2. **文档结构问题**：7 份文档可能在 chunk 切分时关键信息被切断（如资格条件、时间节点等精确数据）
3. **检索召回不足**：查询"补考"时可能漏掉"重修""缓考"相关 chunk

### 建议

- 审查这 7 份文档的 chunk 切分方式，确保每条规定完整独立
- 增加补考相关问题的 prompt 模板变体（口语化问法）
- 确保补考 + 重修规定文档的检索权重足够高
- 在 sources.csv 中提高补考相关来源的 priority
