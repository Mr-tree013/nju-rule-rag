# 南京大学NFC校园卡完全指南

## 功能简介

开通NFC校园卡后，无需手机解锁，NFC区域轻轻一碰即可使用：

### 校内功能
- 校门通行
- 食堂就餐
- 超市消费
- 图书馆借阅
- 校园巴士乘车
- 苏州校区宿舍/办公室门禁

### 校外功能
- 南京公交/地铁
- 出租车/轮渡/有轨电车
- 全国300+城市公共交通

注意：南京校区（仙林、鼓楼、浦口）的宿舍门锁、校门闸机、院系门禁目前尚未对接NFC。只有贴有NFC标识的设备才支持。

## 支持机型

iPhone：iPhone 6s及以上，iOS 14.0+，Apple Watch Series 3及以上（watchOS 7.4+）

安卓/鸿蒙：华为P系列/Mate系列、荣耀大部分型号、OPPO Find/Reno系列、vivo NEX/iQOO/X系列等

三星、小米、一加等品牌暂不支持在APP端开卡。

## 开通步骤

1. 下载"南京市民卡"APP（iOS ≥1.1.4，Android ≥1.1.3）
2. 打开APP → 点击"实体卡"→ 完成实名认证
3. 找到"校园联名卡"→ 点击"立即开通"
4. 输入南京大学统一身份认证的用户名和密码
5. 开通完成，卡片自动添加到手机钱包

开卡免费，无需支付开卡服务费。

## 使用方法

1. 打开手机NFC开关
2. 苹果：设置 → 钱包与Apple Pay → 将联名卡设为快捷交通卡
3. 安卓/鸿蒙：钱包APP → 设置默认卡片 → 选择南大NFC校园卡
4. 将手机NFC天线区域（一般位于顶部摄像头附近）靠近刷卡区

设置快捷交通卡后，刷卡无需亮屏、无需解锁，部分机型支持低电量关机后仍可刷卡2-4小时。

## 充值

| 使用场景 | 充值渠道 |
|---------|---------|
| 校内消费（扣校园卡余额） | 南京大学APP / 微信"南京大学信息门户" / 校内自助终端 |
| 校外交通（扣金陵通钱包） | 南京市民卡APP / 手机钱包Wallet |

## 常见问题

- 每部手机仅能开通1张NFC校园卡
- 无法消费时检查是否设为默认卡
- 已有金陵通卡需先移除或迁移至云端，再开通南大NFC校园卡
- 手机丢失先解绑，再通过云服务清除数据
- 毕业/离校后绑定自动解除，卡片保留交通功能
- 解绑在南京大学APP → 校园卡服务 → NFC → 解绑（不可逆）
- 退卡满30天后可在南京市民卡APP操作，余额退回支付宝（余额≥10元收10%手续费）

## 校园卡常规功能

校园卡支持：食堂消费、超市购物、图书馆借阅、门禁通行、浴室水控、自助打印、校园巴士、医疗挂号。校园卡仅限本人使用，不得转借他人。可通过南京大学APP、微信"南京大学信息门户"公众号、校内自助终端充值。

## 校园卡丢失处理
- 第一时间挂失：南京大学APP → 校园卡 → 挂失
- 补办：携带身份证到校园卡管理中心（仙林：信息化中心一楼，鼓楼：综合服务大厅）
- 补办费用：20元工本费
- 捡到他人校园卡应交回校园卡管理中心
